# 乔古曼主题

首页参照 mession18.github.io 的场景式首屏、固定导航、最近文章、收藏拍立得、餐饮便笺、厨房、户外明信片和生活护照组织内容。角色栏目仍以 `content/site.json` 为准。

## 文件

- `public/modules/island.js` / `island.css`：首页、栏目封面与生活护照。
- `public/modules/widgets.js` / `widgets.css`：天气、日历、时钟与音乐播放器。
- `public/assets/scenery/SOURCES.md`：背景素材来源。角色采用现有 JOGUMAN 原素材。
- `pet.js` / `pet.css`：左下角的布拉吉奥动画。

## 栏目与封面

布拉吉奥＝收藏；迪波罗＝出去吃饭；安基罗＝在家做饭；史铁哥＝户外；崔卡拉＝其他；伍迪＝小黑猫金子。

三个旧示例封面自动显示为对应栏目角色插画。新上传图片保持原图路径，并在卡片内裁切显示。首页计数、文章与护照统计都来自实际内容；金子尚无文章时显示等待照片和故事的空状态。

## 小组件

天气使用 Open-Meteo，默认参考杭州，可搜索更换城市；不自动申请定位权限。选择与缓存保存在浏览器本地。日期、农历、文章日期标记和时钟以北京时间显示。自动日夜主题在 19:00–05:00 使用夜间模式，也可手动切换或在天气面板恢复跟随日夜。

播放器内置两段原创合成轻音乐，首次播放时在浏览器生成。支持切歌、进度、音量、循环与随机播放，切换文章不会中断音乐。可加入本地音频；文件不上传，刷新页面后移除。

本主题为个人非官方主题，角色版权归 JOGUMAN。示例文章请替换为自己的内容。
