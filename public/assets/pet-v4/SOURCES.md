# 标准站姿布拉吉奥与小门

更新日期：2026-10-23。

- 当前角色使用 `brachio-front.svg`：正面偏侧、双眼可见的完整站姿，来自 JOGUMAN 官网 <https://en.joguman.com/home/> 的 `.brachio .lf-ver` 矢量画。源文件保存在 `../brachio-original.svg`；2026-10-23 重新抓取官网核验，源文件全部 24 条绘图路径与官网一致。
- 派生 SVG 只移除官网白天模式已隐藏的 `.gun`、`.fire`、`.brow` 与对应隐藏样式；其余可见路径的 `d`、填色、描边及父层级保持原样，原地面阴影的透明度与混合方式也保留。画布收紧为 `viewBox="58 0 156 306"`，增加动画分组标记，并将整幅角色镜像，使左下角的默认站姿朝向页面右侧；原始 SVG 未修改。
- 当前宠物已停止使用掉落姿势的 `brachio-pet.json` 与 Lottie 播放器。旧文件保留供现有引用兼容，当前 `pet.js` 不加载它们。
- 头部跟随是本站制作的二维网页动效，并非官方动画或三维模型：以官方连续的身体、颈部、头部轮廓为基础，对原矢量坐标做连续形变；颈部逐渐过渡到固定身体，避免分层裁切接缝。`data-pet-rig="body"` 标记这一整条连续轮廓。
- 嘴巴与双眼保留官方路径，分别标记为 `mouth`、`eye-near`（原图左眼）、`eye-far`（原图右眼），供网页同步头部与面部视线；没有从侧面图片拼接另一张脸。静态回退图与动态角色使用同一幅镜像的正面偏侧原画。
- 指针位置采用柔性限幅、按帧时间平滑过渡；指针离开页面时轻轻回正，目标位置稳定后停止动画帧。触屏滑动不触发跟随；拖动、开门、暂停、系统减少动态效果、后台和阅读自动收起时头部回正。
- `door-frame.svg` 和 `door-panel.svg` 是本站独立绘制的小门 UI，不属于 JOGUMAN 官方角色素材，也未将其标成官方插画。
- 出入采用门扇绕铰链旋转、角色等比例横向平移、轻微踏步摇摆和固定门口裁切。没有将整个角色缩放或拉伸。门默认在站位右侧，靠近右屏边时改至左侧。
- 暂停、系统减少动态效果、窗口失焦、页面后台、位置重排、隐藏/召唤中断以及销毁组件都会结束待完成的门动画。门不接收指针事件，静止时不可见。
- `localStorage['slow-notes-pet']` 的隐藏、暂停、相对位置格式及模块接口保持兼容。
