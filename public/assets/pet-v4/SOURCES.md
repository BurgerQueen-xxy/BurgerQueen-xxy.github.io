# 标准站姿布拉吉奥与小门

更新日期：2026-10-23。

- 角色仍直接读取 `assets/brachio.png`（186 × 360），来源为 JOGUMAN 官方：<https://cdn.jogumancdn.com/images/projects/character_8.png>。原文件未修改。头、身体、手臂、鞋子和尾巴使用原图像素。
- 当前宠物已停止使用掉落姿势的 `brachio-pet.json` 与 Lottie 播放器。旧文件保留供现有引用兼容，当前 `pet.js` 不加载它们。
- 头部跟随是本站制作的二维网页动效，并非官方动画：SVG 分层裁切原图头部和身体，头部按鼠标位置小幅侧转、抬起或低下，身体和脚保持原位。上颈与身体之间用原图颜色 `#27b67c` 的曲线连接并重叠，避免旋转时出现断口；不翻转整张角色图。
- 眼睛跟随通过 SVG 的原图副本裁切实现：取原图 `(64,33)` 起的 `12 × 12` 眼部区域，原眼部位置补上与周边完全一致的 `#27b67c`，将裁切的原始眼睛像素轻微平移。眼睛嵌套在头部分层内，随头部共同移动。静止时眼睛与原图一致。
- 指针位置采用柔性限幅、按帧时间平滑过渡；指针离开页面时轻轻回正，目标位置稳定后停止动画帧。触屏滑动不触发跟随；拖动、开门、暂停、系统减少动态效果、后台和阅读自动收起时头部回正。
- `door-frame.svg` 和 `door-panel.svg` 是本站独立绘制的小门 UI，不属于 JOGUMAN 官方角色素材，也未将其标成官方插画。
- 出入采用门扇绕铰链旋转、角色等比例横向平移、轻微踏步摇摆和固定门口裁切。没有将整个角色缩放或拉伸。门默认在站位右侧，靠近右屏边时改至左侧。
- 暂停、系统减少动态效果、窗口失焦、页面后台、位置重排、隐藏/召唤中断以及销毁组件都会结束待完成的门动画。门不接收指针事件，静止时不可见。
- `localStorage['slow-notes-pet']` 的隐藏、暂停、相对位置格式及模块接口保持兼容。
